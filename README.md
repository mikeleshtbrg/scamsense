# scamsense
Early-warning scam detector for in-game trading chats (Steam, Roblox, Discord). Reads chat messages + trade events and flags legit vs. 6 scam types (fake middleman, fake payment, item swap, phishing, impersonation, fake support) before the player acts. mDeBERTa trained on synthetic chats, tested on real ones. EN + HE-EN. LLM4NLP project.
